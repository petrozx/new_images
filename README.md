# Окно 1С без «КОРП»

Скриншоты и инструменты, чтобы в заголовке рабочего окна
**Управление холдингом, редакция 3.3 (1С:Предприятие КОРП)**
не оставалось слова **КОРП**.

Нужный вид заголовка:

`Управление холдингом, редакция 3.3 (1С:Предприятие)`

## Автоправка своих скриншотов

Положите исходные PNG/JPG в `images/original/` и выполните:

```bash
pip install pillow pytesseract
# нужен tesseract с русским языком: tesseract-ocr tesseract-ocr-rus

python3 scripts/remove_korp_from_title.py images/original -o images
```

Скрипт ищет «КОРП» в верхней полосе окна (OCR) и закрашивает его цветом фона заголовка.

## Живая система 1С

Слово **КОРП** в суффиксе `(1С:Предприятие КОРП)` добавляет **платформа КОРП-лицензии**. Штатными средствами убрать только это слово нельзя: `КлиентскоеПриложение.УстановитьЗаголовок()` меняет пользовательскую часть слева, системный суффикс платформы остаётся.

Что можно сделать в базе:

1. **Пользовательский режим:** НСИ и администрирование → Общие настройки → «Заголовок программы».
2. **Расширение:** код в `1c-extension/МодульПриложения.bsl` — задаёт левую часть заголовка при старте сеанса.

Для документации и презентаций правьте скриншоты (готовые файлы выше или скрипт).

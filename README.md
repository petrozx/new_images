# Правка заголовка 1С: убрать «КОРП»

Нужно изменить только текст в шапке окна:

**было:** `Управление холдингом, редакция 3.3 (1С:Предприятие КОРП)`  
**нужно:** `Управление холдингом, редакция 3.3 (1С:Предприятие)`

Остальной скриншот без изменений.

## Как отдать исходный скрин

1. Положите ваш PNG/JPG в папку `images/original/`
2. Напишите агенту «готово» — скрипт уберёт только слово **КОРП** и сохранит результат в `images/`

Или локально:

```bash
pip install -r requirements.txt
# нужен tesseract-ocr + tesseract-ocr-rus

python3 scripts/remove_korp_from_title.py images/original/ваш-скрин.png \
  -o images/ваш-скрин-bez-korp.png
```

## Файлы

- `scripts/remove_korp_from_title.py` — точечное удаление «КОРП» с заголовка
- `images/original/` — сюда исходники
- `images/` — сюда результат

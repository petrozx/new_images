# Правка заголовка 1С

Нужно **только** убрать слово `КОРП` из текста:

`Управление холдингом, редакция 3.3 (1С:Предприятие КОРП)`  
→ `Управление холдингом, редакция 3.3 (1С:Предприятие)`

Стили, таблица и остальной скрин **не меняются**.

## Что сделать

1. Откройте репозиторий на ветке `cursor/1c-okno-bez-korp-c001`
2. Загрузите ваш PNG сюда: **`images/original/`**
   - GitHub → Add file → Upload files
3. Напишите агенту «готово»

Скрипт `scripts/remove_korp_from_title.py` закрасит только «КОРП» цветом фона шапки и сохранит результат в `images/`.
